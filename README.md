# Neko

Neko is a Lua runtime for running Lua in the browser.

It uses [Lunar](https://github.com/kindtracker/lunar) and provides Lua APIs for interacting with web pages, browser APIs, and HTML elements.

## Get Started

First, clone Neko somewhere outside your project and build it:

```sh
chmod +x build.sh
./build.sh
```

Then copy `web/nekol` and `wbundle.lua` into your new project.

Create a `main.lua` file:

```lua
local Page = Neko.Page

local Div = Page.new("Div")
Div.InnerHtml = "cat generated this div :3"
Div.Parent = Page.Body
```

Your project should look something like:

```text
New Project
├── wbundle.lua
└── web
    ├── index.html
    ├── nekol
    └── main.lua
```

Bundle your project by running:

```sh
lua wbundle.lua
```

Then start an HTTP server from the `web` folder:

```sh
cd web
python3 -m http.server
```

Open the local server in your browser.

You should see the following `<div>` generated by Lua:

```html
<div>cat generated this div :3</div>
```

## Building

### Requirements

* Lua
* Emscripten / EMCC
* Bash

Build Neko with:

```sh
chmod +x build.sh
./build.sh
```

The generated browser runtime will be placed in `web/nekol`.
